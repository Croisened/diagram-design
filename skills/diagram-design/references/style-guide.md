# Style Guide

**The single source of truth for colors, typography, and tokens.** Every diagram draws from this — not from hex values inlined in other reference files. If you want to change the visual skin of Schematic, change this file.

Current skin: **Fully Croisened** — dark-first cyberpunk. Deep terminal-black paper, near-white ink, FC-cyan accent (`#1FBFD6`, derived from the logo). Onboarded from `https://fullycroisened.com` on 2026-04-23. This is a dark-mode-first skin; the light column is generated via inversion for light-mode exports.

To regenerate from a different URL, see [`onboarding.md`](onboarding.md).

## Tokens

### Semantic roles

Every token is referred to by **semantic role**, not by its hex value. Type references (`type-*.md`) and SKILL.md say `accent`, not `#f7591f`.

| Role | Purpose | Default (light) | Default (dark) |
|---|---|---|---|
| `paper` | Page background, default node fill | `#FAFCFD` (fc-paper) | `#0A0E12` (terminal-black) |
| `paper-2` | Diagram container bg, secondary fill | `#F2F5F7` | `#131921` |
| `ink` | Primary text, primary stroke | `#05080A` | `#F2F5F7` |
| `muted` | Secondary text, default arrow stroke | `#4B5968` | `#C7CED5` |
| `soft` | Sublabels, boundary labels | `#6D7B8A` | `#9AA6B2` |
| `rule` | Hairline borders | `rgba(5,8,10,0.10)` | `rgba(255,255,255,0.10)` |
| `rule-solid` | Stronger borders, baselines | `#C7CED5` | `#33404F` |
| `accent` | Focal / 1–2 max per diagram | `#1FBFD6` (FC cyan) | `#1FBFD6` (FC cyan) |
| `accent-tint` | Fill for accent-bordered boxes | `rgba(31,191,214,0.08)` | `rgba(31,191,214,0.14)` |
| `link` | HTTP/API calls, external arrows | `#0089A1` | `#3FD2E4` |

> **Brand palette source:** mapped from the Fully Croisened design tokens — `--bg-base #0A0E12` (fc-ink-950), `--fg-1 #F2F5F7` (fc-ink-50), `--fg-2 #C7CED5` (fc-ink-200), `--fc-cyan-400 #1FBFD6` (core logo cyan), `--fc-cyan-300 #3FD2E4` / `--fc-cyan-600 #0089A1` for link. The site also defines neon secondaries (magenta `#FF3DE2`, lime `#C6FF3D`, violet `#8A5CFF`) — intentionally not mapped, because the focal rule allows only one accent. Use them manually if a diagram needs a signaling third color.

> **Primary mode is dark.** The site is cyberpunk-dark-first. Treat the dark column as the native skin; the light column is an inversion for light-mode exports (use `template-dark.html` as the default template, `template.html` for light exports).

### Inversion rule (dark → light)

Since this skin is dark-native, the light variant is generated by inversion. Any `rgba(5,8,10, X)` in light becomes `rgba(255,255,255, X)` in dark — same opacities, ink-RGB flipped. The accent `#1FBFD6` stays identical across both modes (the cyan reads as focal on both `#0A0E12` and `#FAFCFD`). `link` shifts between a lighter cyan on dark (`#3FD2E4`) and a deeper cyan on light (`#0089A1`) to maintain AA on body text.

## Typography

| Role | Family | Size | Weight | Usage |
|---|---|---|---|---|
| `title` | Chakra Petch | 1.75rem | 700 | Page H1 — angular geometric display |
| `node-name` | Space Grotesk | 12px | 600 | Human-readable labels |
| `sublabel` | JetBrains Mono | 9px | 400 | Port, protocol, URL, field type |
| `eyebrow` | JetBrains Mono | 7–8px | 500, tracked 0.18em, uppercase | Type tags, axis labels |
| `arrow-label` | JetBrains Mono | 8px | 400, tracked 0.06em | Arrow annotations |
| `callout` | Instrument Serif *italic* | 14px | 400 | Editorial asides only |

### Font stack

```html
<link href="https://fonts.googleapis.com/css2?family=Chakra+Petch:wght@500;600;700&family=Space+Grotesk:wght@400;500;600&family=JetBrains+Mono:wght@400;500;700&family=Instrument+Serif:ital@1&display=swap" rel="stylesheet">
```

**Load-bearing rule:** Mono is for *technical* content (ports, commands, URLs, field types) — JetBrains Mono is used here because it's the brand mono and only appears in those technical roles, never as a blanket "dev" font. Names go in Space Grotesk. Page title is Chakra Petch (angular, geometric — the brand display face). Italic Instrument Serif is still reserved for annotation callouts (see [primitive-annotation.md](primitive-annotation.md)) — the serif-italic-in-the-margin contrast against the angular display + humanist sans is load-bearing and doesn't come from the brand fonts.

## Customizing the skin

Three options:

1. **Run onboarding** — see [`onboarding.md`](onboarding.md). Drop a URL; the skill extracts the palette + fonts and rewrites this file.
2. **Edit by hand** — change the hex values in the tables above. Run the pre-output taste gate afterward to verify the accent still reads as "focal" against the new paper color.
3. **Brand handoff** — paste your existing design-token JSON into a new section here and map its tokens to the semantic roles above.

### Constraints (don't break these)

- **Contrast**: `ink` must hit WCAG AA on `paper`. `muted` must hit AA on `paper` for 11px+ text.
- **One accent**: pick one color for `accent`. Two accents erases the focal signal.
- **No rainbow palette**: if your brand ships 8 colors, pick 3 (paper, ink, accent). The rest become `muted` variants.
- **Serif + sans + mono**: three families, not more. If brand typography is all sans, keep Instrument Serif for `title` and `callout` anyway — the contrast is load-bearing.
- **Paper is warm-neutral, not pure white**: pure white turns the design sterile. Pick a cream, bone, or light grey with a hint of warmth.
- **Dot pattern is optional, not default**: the 22×22 dot pattern is an opt-in "dotted paper" variant (good for long-form editorial hero diagrams). The default background is a clean `paper` fill, no pattern. When the pattern is enabled, it should sit at ~10% opacity of `ink` on `paper` — visible but quiet.
- **Container is clean by default**: the diagram sits directly on the page paper, no secondary container background or border. A framed variant (`paper-2` bg + `rule` border + 8px radius + padding) is available as an opt-in for card-heavy layouts, but don't reach for it by default — the extra chrome fights the figure.
