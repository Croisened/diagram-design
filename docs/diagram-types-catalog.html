Tree · Diagram Design

Thirteen templates, one grammar

Every diagram the skill can produce. Three categories fan out from one root — flow, structure, position. Each leaf is a type; pick the one that matches the axis of the story you're telling.

HOW TO PICK

One axis at a time

If your story is about change, look in Flow & Time. If it's about shape, look in Structure. If it's about where things sit, look in Position. Hybridizing across columns is usually a sign the diagram wants to be two diagrams.

Three variants each

  • Minimal light — screenshot-ready
  • Minimal dark — slides, dark sites
  • Full editorial — cards + subtitle
  • Quadrant adds a clinical BCG-style 2×2

When not to draw

If a 3-column table communicates the same thing, pick the table. If the diagram would be a single labeled box, write the sentence instead. Would a reader learn more than from a well-written paragraph?
